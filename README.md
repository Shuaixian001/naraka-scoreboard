# 永劫无间赛事积分表

一个**单文件、零依赖、纯前端**的《永劫无间》赛事积分表。双击 `index.html` 就能用，不用装任何东西，不用联网。

## 在线使用

**https://shuaixian001.github.io/naraka-scoreboard/**

打开就能用，数据存在你自己的浏览器里，不会上传到任何服务器。

## 功能

### 赛制

- **积分制**：`总积分 = 排名分 + 击败分`
- **赛点制**：可配置赛点分数（默认单排 16 / 三排 40）与最大局数（默认 8 局）
  - 实时标记谁已开启赛点，带进度条显示还差多少分
  - 开启赛点后再拿到一次单局第一即自动判定夺冠
  - **赛点排名分**：开启后自下一局起每局递增（单排 +0.5 / 三排 +1），可开关
  - 打满仍无冠军则按总积分定冠军
  - 达阈当局取胜是否算夺冠可配置（官方规则为「**再**获得一次」，默认关）

### 对局类型

- **天人对局**：排名分 + 击败分，用天人排名分表
- **武道对局**：只有排名分，用独立的武道排名分表，没有击败分输入框
- 每局的类型可在录入界面随时切换，新建赛事的第一局默认是武道

### 积分构成

`总积分 = 前序积分 + 武道对局积分 + 天人对局积分`

- **前序积分**：每个参赛者可直接填一个带入分，计入总积分，也参与赛点开启判定
- 前序分不计入单局得分（单局第一仍按当场所得比较）

### 分组（小组赛）

- 每个参赛者归属一个组（A/B/C…），每局可选择参与组（单组 / 跨组 / 全员）
- 积分榜可切「合并总榜」或各组榜；组榜只是行过滤 + 组内重排，分数口径与总榜一致
- 支持随机平均分组、组改名（自动同步所有引用）、批量按 `[A] 队伍名` 前缀建组

### 多人规模（8-48 人/队）

- 批量粘贴名单：单排每行一个名字；三排 `队伍名 / 成员1 / 成员2 / 成员3`
- 录入网格支持 **Enter / ↑ ↓ / ← → 键盘流**（左右可跨行一路走完整张表）、未录入高亮、跳到未录入、大名单搜索
- 积分榜每局一列，只显示该局总分，**该局最高分自动高亮**
- 积分榜**默认展开全部**，超过 8 人时给「收起」按钮，也可拖右下角手动调高矮

### 实时积分榜

- **简表 / 完整表一键切换**：简表只留 `排名 / 组 / 队伍 / 总分 / 赛点状态`，把前序与每局列折叠起来，适合投屏和播报
- **赛点制下夺冠选手立刻置顶**为第一名，其余整体下移一位
- 淘汰赛名次着色：可自定义规则（如 5-8 名标灰），整行上色

### 其他

- 并列裁定：单局最高分并列时弹窗人工裁定高亮哪一个（默认预选官方同分顺序的人）
- 总分并列且同分规则分不出先后时，在右侧「同分裁定」里**按你想要的顺序依次点名字**；再点一下可取消
- 结束积分：一键锁定赛事，禁用所有录入操作防止误触，可随时解锁
- 多赛事管理，单排/三排各自独立
- 数据导出 / 导入 JSON
- 排名分表可逐格编辑，内置官方 8 人制、12 人制梯度预设

### 批量管理赛事

「设置 → 数据」里除了单个赛事的导出 / 导入 / 删除，还有一组批量操作：

- **批量导入**：「导入赛事（可多选）」一次选中多个 JSON 文件，全部读入后弹一次确认框列出所有赛事名。
  读不了的文件会被单独列出并跳过，不会因为一个坏文件中断整批；同名赛事自动加「（导入）」后缀
- **批量导出**：点「批量管理赛事…」勾选任意多个赛事，两种导出方式
  - *导出为一个文件*：打包成 `{events:[...]}`，之后导入可一次全部还原
  - *逐个导出*：每个赛事一个文件，用各自的赛事名命名
- **批量删除**：同一个弹窗里「删除选中」。确认框会列出完整赛事名；
  全选删除时还会再确认一次。删掉当前正在看的赛事会自动切到剩下的那个

> **关于「逐个导出」**：浏览器会在开头询问「是否允许下载多个文件」，选**允许**即可。
> Edge 和联想浏览器实测都会正常提示并下载。如果浏览器默认拦截又不弹提示，
> 改用「导出为一个文件」打包导出更稳妥。

## 使用提示

1. **排名分表请按当季官方规则核对一遍再开赛。** 规则每个赛季都会变，内置的默认值（官方 8 人制：单排 `2.5/1/0.5/0.5`，三排 `4/2/1/1`）只是一个起点，在「设置 → 排名分表」里可以逐格改。
2. **数据存在浏览器本地**（localStorage）。换电脑、换浏览器、或者清理浏览器数据都会看不到之前的成绩，重要赛事请及时用「设置 → 导出数据」备份。
3. 单局同分排序按官方规则：单局总分 → 击败分 → 生存排名。伤害数据没有录入，排序链到此为止。
4. 所有设置设置完成后要点击“保存设置”按钮保存，不然设置不会生效。
## 数据说明

示例数据都在 [`赛事数据/测试数据/`](赛事数据/测试数据) 文件夹里，用「设置 → 导入赛事」逐个载入。

- 第一赛段测试数据包含单排第一赛段决赛、三排第一赛段决赛、第一赛段第二轮败者组三个文件的数据，后续所有更新的数据都是单日数据。

## 本地使用

下载 `index.html`，双击用浏览器打开即可。不需要服务器、不需要构建、不需要联网。
